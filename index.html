Featured Project

Educational Portfolio Project

CityHub — Unified Information Platform of Ukraine's Settlements

Role: Project Manager (Educational Project) · Project Management with AI, Hillel IT School

CityHub was completed independently as the final assignment for the Project Management with AI course. It is a concept for a unified web platform that would organize information about Ukrainian settlements — public institutions, local businesses, and infrastructure — for citizens, IDPs, tourists, and communities. No platform was built or launched, there was no client engagement, and no real project team was managed; this is an educational demonstration of project planning and documentation skills, not a commercial project.

The work covered the planning and documentation stages of a project lifecycle, from initiation through MVP planning, producing a structured set of PM artifacts grouped below.
