Featured Project

Educational Portfolio Project

CityHub — Unified Information Platform of Ukraine's Settlements

Role: Project Manager (Educational Project) · Project Management with AI, Hillel IT School

CityHub is an original project concept that I conceived, planned, and documented independently as the final assignment for the Project Management with AI course at Hillel IT School.

I independently selected the project topic and created the idea, concept, scope, and documentation for a proposed unified web platform that would organize information about Ukrainian settlements — including public institutions, local businesses, and infrastructure — for citizens, IDPs, tourists, and local communities.

Working in the role of Project Manager (Educational Project), I planned and documented the concept from initiation through MVP planning and prepared a structured set of project management artifacts. The platform itself was not developed or launched, there was no client engagement, and no real project team was managed.
